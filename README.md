# チアーズメイト ロードマップ

はじめにからマイルハック開業サポートまでを1本線でたどるロードマップページです。`index.html` 1ファイルで動きます。

## 会員サイトへのリンク

- レッスン名を押すと、会員サイト（`https://member.cheersmate11.com/members/9JcHM2Gb6jwp/course/<コースID>/lesson/<レッスンID>`）のそのレッスンが新しいタブで開きます。
- レッスン一覧は `index.html` の `COURSES`（UTAGEの公開レッスン）に入っています。会員サイトにレッスンを足したら、ここに `[レッスンID, 名前]` を追加し、ロードマップに載せる場合は `STAGES` に `[レッスンID, 動画の長さ, 1]` を足します。
- チェックはレッスンIDで保存します。以前の並び順キー（`s4-0-2` など）は読み込み時に自動で引き継ぎます。
